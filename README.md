## Hi there
I am new to creating GitHub repositories so bear with me. Up till now, I have only used GitHub as a source for FOSS software downloads. I have since moved on to learning Linux and Distro-Hopping.

My Linux distribution of choice right now is openSUSE Slowroll, but I am exploring AnduinOS, Aurora Linux, CachyOS, Fedora, and PopOS. There are many more I will tests, but these are my first round of system to explor.

Since I have 30 years experience with Windows, it should be no surprise to anyone that I am a KDE Plasma fan. I have tried GNOME, but it is too plain for me. I know you can add on to it, but I found the extensions are unstable. I would have much preferred GNOME to have put more of the basic extensions into their base project (even if turned off) so that it would be much more stable.

Tiling window managers like Hyprland are intriguing me. Scrolling window managers more so. My only problem with them is that they are even more stripped down of functionality than GNOME. I am still very much a mouse person and I also like my windows decorations, thus I am not the target audience for these systems.

My current project is learning GitHub and Open Build Service (OBS) so that I can port tarballs (both source and binary archives) between distributions to support my distro-hopping. I have been using distro-boxes for this, but I am finding them limiting for apps that need access to more than my home folder.
